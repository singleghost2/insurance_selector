# 百万医疗险智能选购助手

家庭自用的保险选购辅助网站：上传保险条款 PDF 由 AI 分析优劣势和影响理赔的关键条款、多款对比；为家庭成员建立健康档案（体检报告/病历自动解析），投保时辅助健康告知。

## 快速开始

```powershell
# 1. 安装依赖（建议虚拟环境）
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt

# 2. 配置大模型
copy .env.example .env
# 编辑 .env，填入你的 API Key（默认通义千问 DashScope，也可换 DeepSeek/GLM 等 OpenAI 兼容供应商）

# 3. 启动
python run.py
# 浏览器打开 http://127.0.0.1:8000
```

## 使用流程

1. 首页添加家庭成员（我、老婆、爸、妈）。
2. 「上传条款」创建产品并上传保险条款 PDF，等待 AI 分析（1-5 分钟）。一款产品通常由多份条款文件组成（主险条款 + 附加险条款 + 费率表等），上传时可一次多选，之后也可在产品详情页追加/移除文件后点「重新分析」。
   蚂蚁保（支付宝）里没有 PDF 下载、只能在线看图片的条款，直接复制条款页面的完整链接粘贴到「方式二」即可，系统会自动下载全部条款图片、OCR 识别后分析（约 5-10 分钟）。
3. 查看分析详情：优劣势、11 类关键条款（等待期/免责/续保/外购药…）、原文引用与页码。
4. 满意的产品「加入自选」，在「自选对比」页做多维度对比并生成 AI 总结。
5. 成员页上传体检报告/检查单（PDF 或照片），自动抽取异常指标建立健康档案，可手工修正。
6. 成员页对某款产品做「健康告知核对」，AI 提示哪些健康记录可能需要告知。

## 说明

- 数据全部存本地 `data/` 目录（SQLite + 上传文件），不会上传到任何第三方（除发送给你配置的大模型/OCR API 用于分析）。
- 文字识别（扫描版 PDF、蚂蚁保图片条款、体检报告照片）由 `OCR_ENGINE` 决定：`paddle_api`（PaddleOCR 官方云端 API，默认）/ `paddle`（本地 PaddleOCR，离线免费）/ `vision`（视觉大模型）。DeepSeek 等没有视觉模型的供应商请用前两种。识别结果会缓存，重新分析不重复识别。
- AI 分析仅供参考，条款原文引用会自动与原文核对（未核实的会标注）；投保决策请以官方条款和保险公司核保为准，健康告知务必如实填写。
